# Curso de Frontend

Este repositório foi criado para armazenar os exercícios e projetos desenvolvidos durante as aulas de Frontend da minha formação Full Stack na Treina Recife.

## Sobre o repositório

Aqui registro minha evolução nos estudos de desenvolvimento web. Atualmente, o conteúdo reúne as atividades realizadas até a **aula 9**, e será atualizado conforme o andamento do curso.

## Tecnologias estudadas

- HTML5
- CSS3
- Bootstrap
- JavaScript (em andamento)

## Objetivos

- Praticar os fundamentos do desenvolvimento frontend;
- Criar páginas responsivas e organizadas;
- Aprimorar meus conhecimentos em HTML, CSS e Bootstrap;
- Desenvolver lógica e interatividade com JavaScript;
- Praticar Git e GitHub durante o desenvolvimento dos exercícios.

## Organização

Os exercícios estão separados em pastas de acordo com as aulas e atividades realizadas durante o curso.

## Próximos passos

- Aprofundar os conhecimentos em JavaScript;
- Aprender manipulação do DOM;
- Desenvolver páginas mais interativas;
- Iniciar os estudos de React.
